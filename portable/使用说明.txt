lan-file-hub 便携版 —— 使用说明
================================

一句话：这就是你自己的网盘。文件存在这台电脑上，电脑和手机都用浏览器打开它。

一、怎么开
----------
1. 双击本文件夹里的「启动.cmd」。
2. 右下角会出现一个托盘图标（像个小窗口的图标），启动完成后会弹一句提示，
   里面就写着"手机可打开 http://192.168.x.x:9180/"这样的地址。
3. 想看状态/操作：在托盘图标上点右键：
     启动 / 停止 / 打开网页 / 查看日志 / 打开数据目录 / 使用说明 / 退出
   双击托盘图标 = 直接打开网页。
4. 关闭网页不影响服务；服务一直在后台跑，直到你右键选「停止」或双击「停止.cmd」。

二、手机怎么连
--------------
1. 手机和这台电脑要连在同一个网络：同一个 WiFi，或者电脑连手机开的热点。
2. 手机浏览器打开托盘提示里的那个地址（形如 http://192.168.1.5:9180/），
   建议存成书签，下次直接点。
3. 用账号登录（管理员账号在准备便携包时创建，用户名默认 admin）。

三、给别人发文件
----------------
- 对方有账号：点文件上的「发送给…」→ 输入对方用户名 → 发送；
  对方登录后在自己的「分享给我的」里就能看到并下载。
- 对方没账号：还是点「发送给…」，在最下面点「生成分享链接」，
  把链接（或二维码）发给他，他手机上点开/扫一下就能下载，不用注册。

四、数据在哪 / 怎么备份
----------------------
- 文件与数据库都在本文件夹的 data 目录里（data\storage 是文件，data\pg 是数据库）。
- 备份 = 关掉服务后，把整个 data 目录复制一份到别的地方。

五、常见问题
------------
- 手机打不开：① 手机和电脑是否在同一个网络；② 电脑上的托盘是否显示"运行中"；
  ③ 校园网/公司网可能禁止设备互访，换成手机热点试。
- 想换端口：用记事本打开 app\.env，改 HTTP_PORT 后重启服务。
- 忘了管理员口令：在电脑上跑一次 scripts\create-admin.ps1（开发机上）即可重置提示。
- 首次运行被杀软/防火墙拦：选择"允许访问"（只放行局域网内的这台电脑，不外发数据）。

六、当前版本的限制（先说清楚）
------------------------------
- 只支持 Windows。
- 没有病毒扫描；上传的文件不会被查毒。
- Windows 11 有时会把新出现的托盘图标藏进"隐藏的图标"里：去「设置 → 个性化 → 任务栏 →
  其他系统托盘图标」把它打开，就能一直在右下角看到。
- 第一次运行时，杀毒软件或防火墙可能弹窗询问是否允许：选「允许」（只在你自己的局域网内使用）。
