# 阶段十二：限流、下载控制和安全加固

> 阶段任务书。阶段编号以 `docs/phases/README.md` 为准；规则、命令与红线见项目根 `AGENTS.md`。

阅读 AGENTS.md，执行项目阶段十二。

实现安全和资源保护功能：

1. 实现登录接口限流。
2. 实现上传接口限流。
3. 实现分块上传并发限制。
4. 实现下载限速。
5. 实现请求体大小限制。
6. 实现单文件大小限制。
7. 实现用户存储配额限制。
8. 实现磁盘剩余空间检查。
9. 完善路径穿越防护。
10. 完善文件名和 Content-Disposition 安全处理。
11. 完善 CORS 配置。
12. 完善 Token 过期和错误处理。
13. 完善分享链接随机性和过期校验。
14. 完善 SQL 参数化查询。
15. 检查日志中是否泄露密码、Token、绝对路径和敏感信息。
16. 增加安全响应头。
17. 实现可选的 FileScanner 抽象和 NoopFileScanner。
18. 添加非法请求测试。
19. 添加越权访问测试。
20. 添加限流测试。
21. 添加大请求拒绝测试。
22. 更新安全文档。

必须覆盖的安全场景：

- 未登录读取文件。
- 用户 A 读取用户 B 的文件。
- 用户 A 修改用户 B 的权限。
- 用户 A 使用用户 B 的 upload_id。
- 通过 ../ 读取存储根目录外文件。
- 使用过期分享 Token 下载文件。
- 使用被撤销分享 Token 下载文件。
- 重复提交登录请求。
- 上传超出配额的文件。
- 上传导致磁盘空间不足。

约束：
- 不能以“前端不会发送非法请求”为安全依据。
- 不实现真实病毒扫描时，必须在 README 中明确标注。
