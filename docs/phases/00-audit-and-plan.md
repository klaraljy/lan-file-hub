# 阶段零：项目审计与实施计划

> 阶段任务书。阶段编号以 `docs/phases/README.md` 为准；规则、命令与红线见项目根 `AGENTS.md`。

阅读项目根目录 AGENTS.md，并执行项目阶段零。

任务：
1. 检查当前 Git 工作区状态。
2. 检查仓库目录结构。
3. 检查已有 CMake、package.json、Docker、README、测试和 CI 文件。
4. 检查当前编译环境、C++ 编译器、CMake、Node.js、npm、Docker 是否可用。
5. 检查当前项目是否已经存在用户修改。
6. 不覆盖、不撤销、不格式化用户已有的无关修改。
7. 识别当前项目已经完成的功能。
8. 识别项目缺失的功能。
9. 结合 AGENTS.md 将项目拆分为可独立验证的阶段。
10. 生成 docs/implementation-status.md，记录：
    - 当前项目状态
    - 已完成内容
    - 未完成内容
    - 构建方式
    - 测试方式
    - 发现的问题
    - 推荐实施顺序

约束：
- 本阶段只进行检查、记录和必要的文档创建。
- 不实现业务功能。
- 不修改已有业务代码，除非为了修复无法运行的基础问题。
- 不执行破坏性 Git 操作。
- 最终报告必须说明检查过的文件、执行过的命令和发现的问题。
