# 阶段四：本地对象存储和单文件上传下载

> 阶段任务书。阶段编号以 `docs/phases/README.md` 为准；规则、命令与红线见项目根 `AGENTS.md`。

阅读 AGENTS.md，执行项目阶段四。

实现本地对象存储和单文件上传下载：

1. 定义 ObjectStorage 抽象接口。
2. 实现 LocalObjectStorage。
3. 创建 files 和 file_versions 表。
4. 实现单文件上传 API。
5. 实现流式文件下载 API。
6. 实现文件元数据查询。
7. 实现服务端 SHA-256 计算。
8. 实现基础 READ、WRITE、OWNER 权限检查。
9. 实现安全对象 Key。
10. 实现文件名、文件类型和文件大小校验。
11. 支持 Content-Length。
12. 支持基本的 Range 下载。
13. 添加大文件流式处理测试。
14. 添加非法路径测试。
15. 添加越权下载测试。
16. 添加对象不存在测试。
17. 更新 docs/api.md、docs/storage.md 和 README。
18. 添加前端文件列表。
19. 添加前端单文件上传。
20. 添加前端文件下载。
21. 添加上传进度显示。

约束：
- 禁止将整个文件读入内存。
- 禁止使用原始文件名拼接物理路径。
- 禁止允许用户直接指定存储目录。
- 禁止在 Controller 中直接操作文件系统。
- 使用数据库生成的 UUID 或服务端生成的对象 Key。
- 原始文件名只能作为元数据保存。
- 上传失败时不能返回成功响应。
- 文件对象和元数据不一致时必须记录错误。
- 最终报告必须说明大文件测试方式。
