9. 实现过期回收站清理任务。
10. 实现对象存储异步删除任务。
11. 实现删除失败重试。
12. 添加删除、恢复和永久删除审计日志。
13. 添加删除后恢复测试。
14. 添加目录不存在时恢复测试。

16. 添加对象删除失败重试测试。
17. 添加前端回收站页面。
18. 添加恢复和永久删除确认弹窗。
19. 更新 docs/recovery.md 和 README。

必须实现的接口：

GET    /api/v1/trash
POST   /api/v1/trash/{resource_id}/restore
DELETE /api/v1/trash/{resource_id}/purge

约束：
- 永久删除大量文件时不能长时间阻塞 HTTP 请求。
- 对象存储删除失败不能导致数据库状态被静默修改为成功。
- 恢复操作必须幂等。
- 永久删除必须进行权限检查。
- 管理员操作必须记录审计日志。
