# 阶段七：文件版本和并发修改冲突

> 阶段任务书。阶段编号以 `docs/phases/README.md` 为准；规则、命令与红线见项目根 `AGENTS.md`。

阅读 AGENTS.md，执行项目阶段七。

实现文件版本管理和乐观并发控制：

1. 完善 file_versions 表。
2. 每次成功上传新内容创建新版本。
3. 保存版本号、大小、哈希、对象 Key、创建者和创建时间。
4. 实现当前版本查询。
5. 实现历史版本列表。
6. 实现历史版本下载。
7. 实现恢复到指定历史版本。
8. 支持 If-Match 请求头。
9. 实现版本冲突检测。
10. 版本冲突时返回 HTTP 409。
11. 返回当前版本 ID 和最新版本信息。
12. 防止旧版本覆盖新版本。
13. 为必要的版本更新增加事务和锁。
14. 添加两个用户同时修改同一文件的测试。
15. 添加历史版本恢复测试。
16. 添加重复恢复请求测试。
17. 添加前端版本历史页面。
18. 添加前端版本恢复确认交互。
19. 更新 docs/api.md、docs/recovery.md 和 README。

约束：
- 不允许直接覆盖当前版本对象。
- 旧版本必须保留，直到清理策略明确执行。
- 版本冲突不能静默覆盖。
- 冲突处理必须是可解释的。
- 如果实现冲突副本，必须保留原文件和操作者信息。
