# 阶段十六：GitHub 发布准备

> 阶段任务书。阶段编号以 `docs/phases/README.md` 为准；规则、命令与红线见项目根 `AGENTS.md`。

阅读 AGENTS.md，执行项目阶段十六。

准备 GitHub 发布版本：

1. 完善 README.md。
2. 添加项目功能概览。
3. 添加系统架构图。
4. 添加目录结构说明。
5. 添加本地启动步骤。
6. 添加 Docker 启动步骤。
7. 添加前端启动步骤。
8. 添加数据库迁移步骤。
9. 添加默认管理员初始化步骤。
10. 添加 API 文档入口。
11. 添加上传流程说明。
12. 添加断点续传流程说明。
13. 添加权限模型说明。
14. 添加异常恢复说明。
15. 添加已知限制。
16. 添加性能测试结果，不能伪造。
17. 添加截图或页面录屏。
18. 添加 LICENSE。
19. 添加 CONTRIBUTING.md。
20. 添加 CODE_OF_CONDUCT.md。
21. 添加 SECURITY.md。
22. 添加 CHANGELOG.md。
23. 检查 `.gitignore`。
24. 检查敏感信息。
25. 检查所有 TODO 是否有明确说明。
26. 检查 CI 是否能够通过。
27. 执行完整构建和测试。
28. 生成 docs/release-checklist.md。

README 至少包含：

- 项目简介
- 产品场景
- 核心功能
- 技术栈
- 系统架构
- 快速启动
- API 示例
- 测试方法
- 性能测试
- 安全说明
- 数据持久化说明
- 备份和恢复
- 已知限制
- 路线图
- License

约束：
- 不声称已经实现未完成或未验证的功能。
- 不提交密钥、密码、Token、数据库转储和用户文件。
- 不伪造截图、压测结果或测试结果。
- README 中所有命令必须与实际项目结构一致。
