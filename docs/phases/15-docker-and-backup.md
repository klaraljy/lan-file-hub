# 阶段十五：Docker、部署和数据备份

> 阶段任务书。阶段编号以 `docs/phases/README.md` 为准；规则、命令与红线见项目根 `AGENTS.md`。

阅读 AGENTS.md，执行项目阶段十五。

完善本地部署和生产部署基础：

1. 检查 Dockerfile 是否支持多阶段构建。
2. 减少最终镜像体积。
3. 后端容器使用非 root 用户运行。
4. 完善 docker-compose.yml。
5. 添加 PostgreSQL 健康检查。
6. 添加 Redis 健康检查。
7. 配置服务启动依赖。
8. 配置数据卷：
   - PostgreSQL 数据卷
   - Redis 数据卷
   - 文件对象存储数据卷
9. 添加数据库迁移执行方式。
10. 添加初始化管理员用户方式。
11. 添加备份脚本。
12. 添加数据库恢复脚本。
13. 添加文件对象目录备份说明。
14. 添加环境变量文档。
15. 添加生产环境安全配置说明。
16. 添加反向代理配置示例。
17. 添加 HTTPS 配置说明。
18. 验证全新环境可以启动。
19. 验证重启容器后数据仍然存在。
20. 验证删除并重新创建 backend 容器后文件仍然存在。
21. 更新 README 和 docs/deployment.md。

约束：
- 不把数据库密码写入仓库。
- 不把 JWT_SECRET 写入仓库。
- `.env` 必须加入 `.gitignore`。
- `.env.example` 只能包含示例值。
- 默认开发密码必须在文档中明确说明，并建议启动后修改。
- 无法验证的生产部署能力必须标注为未验证。
