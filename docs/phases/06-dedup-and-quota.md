# 阶段六：文件去重和配额

> 阶段任务书。阶段编号以 `docs/phases/README.md` 为准；规则、命令与红线见项目根 `AGENTS.md`。

阅读 AGENTS.md，执行项目阶段六。

实现文件去重和用户存储配额：

1. 支持根据 SHA-256 查询已有文件对象。
2. 上传初始化时允许进行哈希预检查。
3. 对已经存在的对象实现安全引用。
4. 上传完成时再次执行去重检查。
5. 创建用户存储配额字段。
6. 实现用户已用空间统计。
7. 上传初始化阶段检查配额。
8. 上传完成阶段再次检查配额。
9. 防止并发上传绕过配额。
10. 处理重复文件引用和删除。
11. 设计对象引用计数或安全清理策略。
12. 添加文件哈希索引。
13. 添加配额超限测试。
14. 添加两个并发上传同时检查配额的测试。
15. 添加重复文件上传测试。
16. 更新 API 文档和 README。

约束：
- 不能只相信客户端提供的文件大小和哈希。
- 去重不能绕过权限检查。
- 删除一个文件元数据时不能误删仍被其他版本引用的对象。
- 配额计算必须明确是否包含历史版本和回收站文件。
- 该规则必须写入文档并通过测试验证。
