# 使用说明（大白话版）

> 这份是**给普通人看的**：怎么启动、手机怎么连、文件怎么给对方。
> 技术细节看 `docs/` 里的设计文档，这里只说"点哪里"。

## 0. 一句话理解这个软件

它就是你**自己的网盘**：文件存在**这台电脑**上，电脑和手机都用**浏览器**打开同一个地址来用。

---

## 1. 怎么启动（每次要用的时候）

1. 双击桌面上的 **`lan-file-hub`** 按钮，出来一个小菜单。
2. 按 **`1`** 回车（直接按回车也行）。第一次可能要等 **1–3 分钟**（要先把数据库拉起来）。
3. 跑完会打印地址，看这两行就够：

   ```text
   前端: http://127.0.0.1:5173                    ← 电脑上用这个
   📱 手机访问: http://192.168.43.240:5173        ← 手机上用这个
   ```

4. **电脑和手机必须连在同一个网络里**（同一个 WiFi，或者电脑连手机的热点）。
5. 用完想关：回到菜单按 **`2`**。

### ⚠️ 那两个黑色命令行窗口是什么

| 窗口标题 | 它是什么 |
|---|---|
| `...\lan_file_hub_server.exe` | **后端**：管文件、账号、数据库 |
| `C:\WINDOWS\system32\cmd.exe` | **前端**：管你看到的网页界面 |

**两个都必须开着**（最小化没关系）。**直接关掉窗口 = 服务停了**，手机和电脑都会打不开。

---

## 2. 手机上怎么用

手机浏览器（Chrome / 自带浏览器都行）打开 **"手机访问"那个地址** → 用**和电脑上一样的账号**登录 → 就能看到文件。

> 建议把这个地址**存成书签**或"添加到主屏幕"，下次点一下就行。
> **换了网络地址会自己变，不用重启**：那个窗口里会打印一行「[网络已变化] 手机现在请用：…」，
> 照着新地址打开就行（分享链接里的地址也会自动跟着更新）。

手机上还能**上传**：进「我的文件」→ 上传 → 选手机里的照片/文件。

### 用手机 App（可选，装一次以后更省事）

App 就是"自己找到电脑 + 帮你看电脑在不在线 + 在 App 里打开电脑网页"：

**最省事的装法（不用找文件、不用数据线）**：

1. 在电脑上打开网页 → 左下角（手机上在底部）「**我的**」→ 找到「**配套手机应用（安卓）**」；
2. 那一行写着**版本、大小、构建时间**（服务器上有新版，这里就是新的），右边有两个按钮：
   - 在**电脑**上：点「**用手机扫码安装**」→ 用手机相机 / 微信「扫一扫」扫那个二维码 →
     手机会**直接开始下载**安装包 → 下完点开，允许「安装未知应用」就装上了；
   - 在**手机**上：直接点「**下载安装**」，下完点开安装。
3. 打开 App → 页面最上面会写「**当前网络：WiFi / 手机热点 / 移动数据**」：
   - 显示 **WiFi** 或 **手机热点** → 稍等两三秒，App **会自己把电脑找出来**，
     出现「发现 1 台电脑 —— 点一下就能用」，点它就在 App 里打开电脑的网页；
   - 显示 **移动数据（流量）** → 连不上电脑，请连上电脑所在的 WiFi，或让电脑连你的手机热点；
   - 一直找不到 → 先确认电脑上的程序开着；如果是校园网/公司网，多半是网络开了
     "客户端隔离"（设备之间不许互相访问），**改用手机热点**再点「找电脑」。
4. 第一次进网页要**登录一次**（和电脑上一样用你自己的账号）。登录页的「**记住我**」默认是勾上的
   —— 勾着的话，这台手机上 **30 天不用再登录**；公用电脑请把勾去掉。
5. 想手动改地址：长按列表里那一条 → 「编辑地址」；删除也是长按。

> 电脑上那个卡片上的**大小和时间**是服务器上现在这份安装包的真实信息 ——
> 我们更新了 App 之后，你刷新一下这个页面看到的就是新数字，不用问人要新文件。

> 也可以老办法：把 `android\lan-file-hub-share.apk` 传到手机（微信/数据线都行）→ 点开安装。

> 另一页「**快传**」是两台手机直接互传（不经过电脑）：一台点开始分享，另一台扫码。

### 把手机相册备份到电脑（装一次、点一下以后很省事）

1. 先在 App 里「**连接电脑**」找到电脑（上一节第 3 步），然后点最下面的
   「**相册备份（把手机照片存到电脑）**」；
2. 第一次要**登录一次**：点「登录 / 换账号」，填电脑上那个账号的用户名和口令
   （口令不会被保存，只保存一张"通行证"）；
3. 点「**选择相册**」，勾上要备份的相册（例如「Camera」就是相机拍的），保存；
   - 第一次会问「照片和媒体」权限 —— 允许它才能读相册（**不会要定位权限**）；
4. 确认勾着「**只在 WiFi / 热点下备份**」（推荐），点「**开始备份**」；
   - 点完会先告诉你「**将上传 N 张照片（约 X MB）**」，你按「开始备份」它才真的传 ——
     **不会点一下就把整个相册全传走**；只传你勾选的相册，别的相册不动；
   - 照片会存到电脑上的「**我的文件 → 手机相册**」里，文件名形如
     `20261003_Camera_IMG_0001.jpg`（哪天、哪个相册、原文件名）；
   - **传过的照片不会再传**；中途停下（点「停止」、换网络、关 App）下次点「开始备份」接着传；
   - 备份时通知栏会显示进度，切到别的 App 也不会中断。
5. 用手机流量时不会传（省流量），页面会写明原因；想强行用流量传就把那个勾去掉。

> **怎么知道手机上装的是不是最新版**：App 首页最下面写着「App 版本 1.0（构建号 2）」，
> 网页「我的 → 配套手机应用」卡片上写着同一个构建号 —— 两个号一样就是最新的。

---

### 找不到文件了？用「搜索」

- 电脑上：左侧点「**搜索**」；手机上：底部「**我的**」→「**搜索**」。
- 输入文件名的一部分就行（例如输入"报表"，能找到"季度报表.xlsx"），**所有文件夹一起搜**。
- 结果里会写清"在「哪个文件夹」"，点一下「去文件夹」就直接跳过去。
- 想看的文件直接点「**查看**」：**图片、PDF、文本**可以在网页里直接看，
  别的类型（压缩包、Office 文档等）网页打不开，点「下载」用电脑上的程序看。
- 回收站里的东西搜不到（要找回它们，去「回收站」）。

## 3. 自己的电脑 ↔ 自己的手机（**同一个账号**）：根本不用"传"
**记住一句话：同一个账号，手机和电脑看到的是同一份文件。**

- 电脑上传了一个安装包 → 手机上打开页面 → 「我的文件」→ 点它 → **下载**
- 手机上上传了照片 → 电脑上**刷新页面**就能看到

不需要分享、不需要扫码、不需要"发送给自己"。你在电脑上登录的账号，手机用同一个账号登录就行。

## 4. 给别人传文件（两个不同账号之间）

### 办法 A：**「发送给…」按钮**（推荐，对方有账号时最直接）

1. 在「我的文件」里找到文件或文件夹 → 点最显眼的 **「发送给…」** 按钮。
2. **① 发给谁**：输入对方的**用户名或邮箱**（至少 2 个字）→ 从下拉里点他。
3. **② 对方能做什么**：默认「只读（可查看与下载）」，也可以选「可写」。→ 点 **「发送」**。
4. 提示会说：**对方登录后，在左侧「分享给我的」里就能看到并下载**。到这一步就完成了。

> 对方那边：登录 → 左侧「**分享给我的**」→ 找到你发的东西 → 点下载。
> 文件可以直接下载；文件夹可以进去浏览。

### 办法 B：发一条链接（**对方不用注册、不用登录**）
同一个「发送给…」弹窗的下半部分就是：

1. 「我的文件」→ 找到文件 → 点 **「发送给…」** → 拉到底部 **「对方还没有账号？」** → 点
   **「生成分享链接」**。
2. 链接**只显示这一次**，马上点「复制链接」，它长这样：

   ```text
   http://192.168.43.240:5173/s/一串字符
   ```

3. 用微信/QQ 把这条链接发给对方 → 对方手机点开就能看详情并**下载**。

> 📷 **对方就在你旁边？直接让他扫码**：生成链接后弹窗里会显示一个**二维码**，
> 用手机自带相机、微信或 QQ 的「扫一扫」对着屏幕扫一下就能打开 —— 不用发链接，也不用登录。

> 链接地址现在由系统自动处理：即使你在电脑上用 `127.0.0.1` 打开页面，它也会**自动换成局域网地址**
> 并提示你（以前就是这里出错，导致手机上打不开）。
> 老的「分享」按钮也能用，规则一样，同样带二维码。

#### 想让对方**必须输密码**才能看？（推荐对外发的时候用）

在「分享」弹窗里创建链接时，除了「有效期」（7 天 / 30 天 / 永久…）和「下载上限」，
还能填一个「**密码**」：

1. 「分享」弹窗 → 填「密码」（例如 `1234`）→ 设置「有效期」和「下载上限」（可选）→ 「创建链接」；
2. 把**链接和密码分开**发给对方（比如链接发微信、密码用别的方式说）；
3. 对方点开链接会先看到「**这个分享需要密码**」，输入后才知道文件名并能下载；
   - 密码**不存在服务器上**（只存一串算不出来的校验值），忘了只能重新生成一条链接；
   - 「下载上限」到了、链接过期了、你点「撤销」了，对方都会看到明确的提示。

## 4.5 手机直接传给手机（**不经过电脑**）

两个人都在外面、身边没有电脑时用这个：**你的安卓手机自己当服务器**。

1. 手机上装 **「局域网快传」**（`android\lan-file-hub-share.apk`）。
2. 打开 App → 「选择要分享的文件」把文件加进来 → 点「**开始分享**」→ 屏幕出现**二维码**。
3. 让对方连上**同一个 WiFi**（或者你手机开的**热点**），用**相机 / 微信扫一扫**那个二维码 →
   浏览器打开 → 点「下载」。对方**不用装 App、不用注册**。
4. 对方也能在这个页面上**上传**文件给你（页面里有「上传给对方」按钮）。

> 这种模式下**手机就是服务器**，所以分享期间别把 App 强行关掉（屏幕上的常驻通知表示它正在工作）。
> iPhone 不能当这种"服务器"，但当接收方没问题（浏览器扫码即可）。

## 4.6 广场：看到谁在线、直接发文件给他

侧边栏（手机上是底部第 2 个 Tab）的「**广场**」是"看人"的地方：

1. 打开「广场」→ **谁在线** 里会列出**同一网络里正在用这套服务的人**（同一个 WiFi 或你的手机热点），
   每张卡上有一个蓝色的 **「发文件给他」**。
2. 点「发文件给他」→ 选一个你自己的文件 → **发给他**。
   对方登录后，在左侧「**分享给我的**」里就能看到并下载。
3. 现在没人？卡片下面会告诉你怎么办：**让同事连上同一个 WiFi（或你的热点），打开你给的那个地址**，
   他就会出现在这里。

**「我的设备」** 这一栏是同一个账号在别的设备上登录（比如你的手机）：
👉 **同一个账号的文件本来就是同一份，不需要"互传"** —— 手机登录同一个账号，
在「我的文件」里直接看、直接下载就行；想快速在手机上打开，可以点「在另一台设备上打开（显示二维码）」。

**不想被看到？** 到「设置」里把「**让别人看到我在线**」关掉（随时可以再打开）。

## 4.7 让别人也能用（邀请注册）

默认**任何人都能自己注册**（自己用方便）。想让"只有被邀请的人才能注册"：

1. 用管理员账号登录 → 左侧「**系统管理**」→「**邀请注册**」标签页；
2. 填个备注（比如"给小王"）→ 点「**生成邀请链接**」→ 屏幕上直接出现**二维码和链接**；
3. 把链接发给对方（微信、QQ 都行），或者让对方**扫这个二维码**；
4. 对方打开后填用户名、邮箱、密码 → 注册成功，直接进系统。

- 一条邀请默认**只能用 1 次**（可以改成多次）；用完、过期或你点「撤销」之后，链接立刻失效。
- 链接**只显示一次**，生成后马上复制或让对方扫码。
- 想彻底关掉自助注册（只能靠邀请）：把便携包 `app\.env` 里的 `ALLOW_SELF_REGISTRATION` 改成 `false`
  再重启服务。关掉之后，没带邀请的人打开注册页会看到"本实例已关闭自助注册"，按钮是灰的。

## 5. 各种组合对照表

| 我想要 | 怎么做 |
|---|---|
| 电脑 → 我自己的手机 | 手机登录**同一个账号**直接下载（见第 3 节） |
| 我自己的手机 → 我自己的电脑 | 手机上传，电脑刷新页面即可看到 |
| 电脑 → **别人**的手机 | 点「发送给…」选人（4A）；或让对方用链接打开（4B） |
| **别人**的东西 → 我的手机/电脑 | 对方「发送给…」给我之后，我在左侧「分享给我的」里看到并下载 |
| 电脑 → 电脑 | 各登各的账号，规则完全一样 |
| 手机 → 手机 | 规则完全一样 |
| 管理员和普通用户有什么不同 | 管理员多一个「**系统管理**」：看所有用户、系统指标、审计日志。普通用户**看不到也进不去**（这是后端判定的，不是藏按钮） |

## 6. 用哪个网络

| 网络 | 能不能用 | 说明 |
|---|---|---|
| **手机热点（最稳，推荐）** | ✅ | 手机开热点 → 电脑连这个热点 → 手机打开"手机访问"地址 |
| 家里 / 自己的路由器 WiFi | ✅ | 电脑和手机连同一个 WiFi |
| 校园网 / 公司网 / 公共 WiFi | ⚠️ 常常不行 | 这类网络经常把设备互相隔离（手机根本找不到电脑）→ 手机上打不开，**换手机热点** |

两条铁律：**① 手机和电脑必须在同一个网络；② 手机用流量（4G/5G）打不开。**

## 6.5 送人用的"便携版"（对方不用装 Docker、不用装 Node）
要把这个东西**拷给朋友/同事用**，用仓库里的 `portable\` 文件夹：

1. 先在你的电脑上准备一次：`scripts\portable-setup.ps1`（会下载一次数据库，约 330 MB；只做一次）。
2. 之后**双击 `portable\启动.cmd`**：右下角出现一个小图标，服务自动跑起来；
   浏览器打开 `http://127.0.0.1:9180/` 就能用，手机的地址看托盘图标提示（形如 `http://192.168.x.x:9180/`）。
3. **不弹命令行窗口、不需要 Docker、不需要 Node**。停止就双击 `停止.cmd`，或右键托盘图标选「停止」。
4. 数据都在 `portable\data\` 里 —— **备份就是把这个目录复制一份**。

> 右键托盘图标还能：打开网页 / 查看日志 / 打开数据目录 / 看使用说明。
> Windows 11 有时会把新图标藏进"隐藏的图标"里，去「任务栏设置 → 其他系统托盘图标」固定出来即可。
> 更细的说明见 [`portable.md`](portable.md) 与 `portable\使用说明.txt`。

### 新增的四个按钮（2026-10-03，都在便携包文件夹里）

| 按钮 | 什么时候用 | 说明 |
|---|---|---|
| **备份.cmd** | 想给数据留个底（建议定期点一次） | 双击就完事：把数据库和所有文件打包到 `portable\backups\<时间>\`。**重要：把备份拷到别的盘或 U 盘**，别和原始数据放同一块盘。里面是账号和文件内容，**别传网盘、别放仓库** |
| **恢复.cmd** | 换电脑、或者弄坏了想回到某一天 | 双击 → 它会列出所有备份 → 输入编号 → 让你确认一次（要输 `yes`）。它会**先把当前状态也备份一份**，再覆盖；中途任何一步不对就停下，不会把数据搞成半截 |
| **开机自启.cmd** | 希望开机后服务自己起来 | 双击 = 打开（在"启动"文件夹放一个快捷方式，**不需要管理员权限**）。想关掉：命令行跑 `portable\tools\autostart.ps1 -Disable`，或直接删掉启动文件夹里那个「局域网文件柜」快捷方式 |
| **自动上传.cmd** | 想让某个文件夹里的东西自动进文件柜（例如扫描件、截图） | 双击后按提示填：① 本地要盯的文件夹（如 `D:\扫描件`）② 电脑上的账号 ③ 服务器上放哪个文件夹（可留空）。之后**丢进去的文件会自动上传**；同一个文件不会重复传。窗口关掉就停止（已经传上去的不受影响） |

### 空间快满了会提醒你

网页上如果出现黄色/红色横幅「空间快满了」，说明**回收站里的东西也算占用空间**：
去左侧「回收站」把不要的**永久删除**，或者删掉一些旧文件。
回收站列表里每一行都会写「还剩 N 天」——超过保留期（默认 30 天）后会被真正清掉。

## 7. 常见问题

| 现象 | 怎么办 |
|---|---|
| 手机上打不开分享链接 | ① 链接是不是 `127.0.0.1` 开头？（新版会自动换成局域网地址；若仍出现，把那段换成启动脚本打印的「📱 手机访问」地址） ② 手机和电脑是不是同一个网络 ③ 电脑上那两个黑窗口是不是被关了 |
| 对方说"没收到"我发的东西 | 让他登录后看左侧「**分享给我的**」（不是「我的文件」）；文件夹要进去才有文件 |
| 「发送给…」里搜不到对方 | 至少输入 2 个字，用户名和邮箱都能搜；对方还没注册的话，用同一弹窗下半部分的「生成分享链接」发链接 |
| 手机上网页能开，但下载失败/卡住 | 看电脑上的后端日志 `%TEMP%\lfh-backend.log` |
| 电脑上也打不开 | 回菜单按 `3` 看状态；显示"未运行"就按 `1` 启动 |
| 想让自己（或某个人）变成管理员 | 打开便携包文件夹，双击「**设为管理员.cmd**」→ 输入用户名（**不用口令、也不会改口令**）→ 重新登录，左侧就出现「系统管理」。命令行等价：`.\scripts\make-admin.ps1 -Username klaraljy` |
| 忘了管理员账号 / 没有管理员 | 同上（把自己已注册的账号提升即可，原密码照旧）；开发环境也可以用菜单按 `5`（那条会要求你输一遍口令） |
| 上传到一半断了 | 重新打开页面、重新选**同一个文件**，它会接着传（断点续传） |
| 想删掉文件 | 删除会先进「回收站」，在里面可以恢复；过一段时间才真正清掉 |
